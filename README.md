##  Proyectos Clave

### 1) Recomendación de Formación Docente
- **Notebook:** Recomendacion_formacion_docente.ipynb
- **Tecnologías:** Python, LightFM, sistemas de recomendación híbridos
- **Descripción:** Modelo que sugiere trayectos de formación personalizados en educación, usando interacciones usuario-item y metadatos sociodemográficos.
- **Impacto:** Mejora la pertinencia y reduce tiempo de búsqueda para docentes.

### 2) Sistema de Recomendación para Amazon
- **Notebook:** Recommendation_Systems_Learner_Notebook_Full_Code_updated (2).ipynb
- **Tecnologías:** Python, Surprise, KNNBasic, filtrado colaborativo
- **Descripción:** Recomendador de productos basado en reseñas de Amazon; se calibró con GridSearchCV para optimizar rendimiento.
- **Impacto:** Modelo robusto para recomendar ítems de alta relevancia.

### 3) Predicción de Clientes Potenciales (EdTech)
- **Notebook:** Learner_Notebook_Full_Code_Version_Potential_Customers_Prediction (2).ipynb
- **Tecnologías:** Python, árboles de decisión, Random Forest, Grid Search
- **Descripción:** Clasificador para identificar leads con alta probabilidad de conversión en una plataforma educativa.
- **Impacto:** Estrategias de marketing más eficientes con priorización de usuarios de mayor valor.

### 4) Segmentación de Clientes y Personalidad
- **Notebook:** Learner_Notebook_Full_Code_Version_Customer_Personality_Segmentation (1).ipynb
- **Tecnologías:** Python, PCA, KMeans
- **Descripción:** Clusterización de perfiles para marketing personalizado; se identificaron segmentos de alto valor y patrones de comportamiento.
- **Impacto:** Mayor precisión en campañas dirigidas y retención de clientes.

### 5) Estudio de Depresión Estudiantil
- **Notebook:** Student_depression.ipynb
- **Tecnologías:** Python, análisis exploratorio, visualización estadística
- **Descripción:** Análisis de factores de riesgo de depresión en estudiantes, con variables demográficas, académicas y conductuales.
- **Impacto:** Insights para intervenciones tempranas centradas en salud emocional.

### 6) Análisis Predictivo de Freelancers (Upwork)
- **Notebook:** FINAL_Upwork_freelancer_Project_training (1).ipynb
- **Tecnologías:** Python, Random Forest, Gradient Boosting
- **Descripción:** Predicción de tarifarios promedio de freelancers usando datos de perfil y habilidades.
- **Impacto:** Rango de precios localizados y recomendaciones para definir tarifas competitivas.

### 7) Segmentación Dental con Deep Learning
- **Notebook:** Tooth segmentation (1).ipynb
- **Tecnologías:** Python, U-Net, segmentación semántica
- **Descripción:** Identificación y segmentación multicategoría de dientes en radiografías panorámicas.
- **Impacto:** Herramienta asistida para odontología basada en visión por computadora.

### 8) Detección de Campos en Facturas (OCR + Segmentación)
- **Notebook:** invoice_field_detection (1).ipynb
- **Tecnologías:** Python, U-Net, MobileNetV2, EasyOCR
- **Descripción:** Pipeline de segmentación + OCR para extraer automáticamente campos clave (empresa, fecha, total) de facturas.
- **Impacto:** Automatización de procesos contables con alta precisión.

### 9) Generación de Música con RNN
- **Notebook:** MusicGenerationTF.ipynb
- **Tecnologías:** TensorFlow, RNN
- **Descripción:** Modelo generativo que produce melodías en notación ABC con patrones aprendidos de música tradicional.
- **Impacto:** Aplicación creativa de IA para composición musical automatizada.
