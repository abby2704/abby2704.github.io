Segmentación Dental Multi-Clase

Deep Learning Computer Vision U-Net Python

Descripción

Desarrollo de segmentación semántica multi-clase para cuantificar análisis dentales, identificando 32 clases de dientes individuales en radiografías panorámicas.

Metodología

Procesamiento de 598 imágenes y >15,000 polígonos, redimensionadas a 128x128. Mapeo de 33 clases semánticas e implementación de una red neuronal U-Net.

Resultados

Pipeline funcional evaluado con métricas robustas al desbalance (IoU, Dice). Se perfiló el dataset para aislar piezas dentales y reducir solapamientos o fugas de bordes.

Detección de Campos en Facturas

Deep Learning Python Computer Vision U-Net OCR

Descripción

Pipeline end-to-end de segmentación y OCR para la extracción automatizada de campos clave (empresa, fecha, dirección, total) en 626 recibos (Dataset ICDAR-2019).

Metodología

U-Net con encoder MobileNetV2 usando transfer learning (encoder congelado + fine-tuning). Generación de máscaras a 256x256 px y extracción final de texto mediante EasyOCR.

Resultados

Segmentación efectiva frente al alto desbalance de fondo, logrando un flujo operativo exitoso integrado en una demo interactiva con Gradio.

Generación de Música con RNN

Deep Learning Python TensorFlow RNN

Descripción

Desarrollo de un modelo generativo de inteligencia artificial capaz de componer música folclórica irlandesa aprendiendo los patrones de miles de canciones representadas en notación ABC.

Metodología

Construcción de una Red Neuronal Recurrente (RNN) utilizando TensorFlow. El pipeline incluyó el procesamiento de secuencias de texto (notas musicales) para entrenar al modelo en la predicción del siguiente carácter de la melodía.

Resultados

El sistema logró generar de manera autónoma secuencias musicales coherentes y originales, convirtiendo la salida de texto directamente a un formato de audio reproducible.
